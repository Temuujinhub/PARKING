# Шинэ зогсоол / түрээслэгч нэмэх заавар

Энэ бол давтагдах ажлын **шалгах хуудас**. Шинэ зогсоол нэмэх, өөрийн QPay
данстай түрээслэгч холбох, өөр нууц үгтэй камер холбох тохиолдол бүрд энэ
дарааллаар явна. Аль ч алхамд код өөрчлөх шаардлагагүй — бүгд тохиргоо.

---

## 1. Зогсоолыг бүртгэх

**UI:** Тохиргоо → Зогсоол → «Зогсоол нэмэх».

**Эсвэл сервер дээр:**

```bash
sudo /root/PARKING/backend/venv/bin/python /root/PARKING/tools/add_site.py \
    --code MYSITE --name "Зогсоолын нэр" --address "Байршил" --capacity 0
```

`--capacity 0` = дүүргэлтгүй. Хэрэглэгддэг бүх сонголтыг `--help`-ээс үзнэ.
Скрипт идемпотент — ижил `--code`-оор дахин ажиллуулж болно.

---

## 2. Хэвлэгдчихсэн QR самбартай бол (ЧУХАЛ)

Заримдаа самбар нь системээс өмнө хэвлэгдчихсэн байдаг. Тэр үед **самбарыг биш,
системийг тохируулна**.

**2.1. Самбарын QR-д ямар линк байгааг тайлах.** Самбарын зургийг серверт
хуулаад:

```bash
zbarimg --quiet --raw /зам/самбар.jpg
```

**2.2. Линкийн хэлбэрээс хамаарч:**

| QR доторх линк | Хийх зүйл |
|---|---|
| `.../pay?site=КОД` | Зогсоолын `--code`-ыг ЯГ тэр КОД-оор өгнө |
| `.../checkout/<uuid>` эсвэл `.../check-cost/<uuid>` | Зогсоолыг ЯГ тэр UUID-аар үүсгэнэ: `--id <uuid>` |

```bash
sudo .../add_site.py --code MYSITE --name "..." \
    --id 565a3ddb-1c01-4201-ad1c-81fc449cbdd7
```

> `--id` нь зөвхөн ШИНЭ зогсоолд үйлчилнэ. Бүртгэгдсэн зогсоолын id-г
> өөрчилж болохгүй — QR нь ажиллахаа болино.

**2.3. Систем үүсгэх QR самбартай ижил болгох.** Самбарын линкийг зогсоолын
«Хэвлэгдсэн самбарын QR линк» талбарт бичнэ (UI: Тохиргоо → Зогсоол → Засах;
эсвэл `--qr-url`). Үүний дараа «Хэвлэх PNG татах» нь самбартай **яг ижил** QR
гаргана — самбар гэмтвэл дахин хэвлээд солиход хуучинтай адилхан ажиллана.

**2.4. Шалгах.** Тэр линкийг утсаараа нээж, зогсоолын нэр зөв гарч байгааг
хараарай. Линк олдохгүй бол сервер лог дээр бичигдэнэ:

```bash
sudo journalctl -u parking-backend --since "10 min ago" | grep "бүртгэлгүй зогсоолын заагч"
```

## 3. Түрээслэгчийн ӨӨРИЙН QPay данс (төлбөр тэдний данс руу)

Түрээслэгч байгууллага өөрийн QPay гэрээтэй бол төлбөр нь **тэдний данс** руу
орж, e-Barimt нь **тэдний ТТД**-ээр үүсэх ёстой.

**UI:** Тохиргоо → Зогсоол → Засах → «Төлбөрийн данс (QPay)» хэсгийг дэлгэж
QPay-гээс ирсэн мэдээллийг бөглөнө:

| Талбар | QPay-гээс ирдэг нэр | Жишээ |
|---|---|---|
| Нэвтрэх нэр | username / client_id | `MONNIS_PROPERTIES` |
| Нууц үг | password / client_secret | (гэрээнд ирсэн) |
| Нэхэмжлэхийн код | INVOICE_CODE | `MONNIS_PROPERTIES_INVOICE` |
| НӨАТ-ын дүүрэг+хороо | district_code | `2318` |

**Эсвэл сервер дээр:**

```bash
sudo /root/PARKING/backend/venv/bin/python /root/PARKING/tools/add_site.py \
    --code MONNIS --name "Моннис билдинг" \
    --qpay-username MONNIS_PROPERTIES --qpay-password '<нууц үг>' \
    --qpay-invoice-code MONNIS_PROPERTIES_INVOICE --qpay-district-code 2606
```

**Заавал мэдэх зүйлс:**

* **Нэвтрэх нэр БОЛОН нууц үг хоёулаа** бөглөгдсөн үед л өөрийн данс идэвхжинэ.
  Ганцыг нь бөглөвөл системийн ерөнхий данс үйлчилсээр байна (хагас тохиргоогоор
  төлбөр буруу данс руу орохоос сэргийлсэн).
* Өөрийн данстай зогсоол **үргэлж бодит горимд** ажиллана — систем бүхэлдээ
  туршилтын (mock) горимд байсан ч тэр. Бодит гэрээтэй түрээслэгчийн төлбөрийг
  хуурамчаар боловсруулахгүй.
* Дүүргийн код = **дүүрэг(2 орон) + хороо(2 орон)**. Жишээ: `2318` = Хан-Уул
  18-р хороо. Буруу код өгвөл QPay `CLASSIFICATION_CODE_INVALID` төрлийн алдаа өгнө.
* Нууц үг **API-аар хэзээ ч буцаагддаггүй** (зөвхөн «хадгалагдсан» гэсэн тэмдэг),
  аудитын логт ч бичигддэггүй. Солих бол дахин бичнэ; хоосон болгож хадгалвал
  устаж, ерөнхий данс руу буцна.
* Токеныг мерчант тус бүрд тусад нь кэшлэдэг (QPay-ийн шаардлага: токеныг
  хугацаанд нь нэг л удаа авах). Өөр өөр гэрээ хоорондоо холилдохгүй.

### Дансыг ШАЛГАХ (машин орох шаардлагагүй)

Тохиргоо → Зогсоол → Засах → «Төлбөрийн данс (QPay)» → **«Дансыг турших»**.

1. Дүнг оруулна (default 10₮ — жинхэнэ мөнгө тул бага дүн).
2. «Нэхэмжлэл үүсгэх» → QR гарч ирнэ. Дээр нь ямар мерчант, ямар нэхэмжлэхийн
   код, ямар дүүрэг ашиглагдаж байгаа нь бичигдэнэ. Хэрэв «системийн ерөнхий
   данс!» гэж улаанаар гарвал тухайн зогсоолын данс идэвхжээгүй байна —
   нэвтрэх нэр/нууц үг хоёулаа хадгалагдсан эсэхийг шалгана.
3. QR-ыг банкны апп-аар уншуулж төлнө.
4. «Төлөгдсөн эсэхийг шалгах» → e-Barimt автоматаар үүсэж **ДДТД, сугалаа,
   баримт олгосон ТТД** гарч ирнэ.

**Эцсийн баталгаа:** гарч ирсэн «Баримт олгосон ТТД» нь **түрээслэгчийн** ТТД
байх ёстой. Хэрэв системийн үндсэн байгууллагынх гарвал данс буруу холбогдсон.

Энэ туршилт нь зогсоолын бүртгэл (session/payment) үүсгэхгүй тул тайлан,
орлогын тооцоог бохирдуулахгүй. Аудитын логт `QPAY_TEST` гэж үлдэнэ.

Дараа нь бодит урсгалыг ч шалгаж болно: тухайн зогсоолын QR-аар машин
төлүүлээд QPay порталтай тулгана. Гүйлгээний утга нь
`КОД-МАШИНЫДУГААР-ОГНОО-XXXXXX` хэлбэртэй тул олоход амархан.

## 4. Камер / хаалт холбох

```bash
sudo /root/PARKING/backend/venv/bin/python /root/PARKING/tools/add_camera.py \
    --site MYSITE --entry 10.0.101.10 --exit 10.0.101.11
```

Хаалтыг гараар нэмэх шаардлагагүй — камер бүрд ижил эгнээний хаалт автоматаар
үүснэ (Dahua ANPR кит хаалтаа камерынхаа релеэр удирддаг).

### Камер өөр нууц үгтэй бол

Зогсоол бүрийг өөр өөр байгууллага суурилуулдаг тул нууц үг ихэвчлэн өөр байдаг.
Камер тус бүрд нэвтрэлт өгч болно:

**UI:** Тохиргоо → Төхөөрөмж → камерыг засах → «Нэвтрэх нэр / Нууц үг».
Хоосон үлдээвэл `.env`-ийн ерөнхий утга үйлчилнэ.

**Эсвэл:**

```bash
sudo .../add_camera.py --site MYSITE --entry 10.0.101.10 --exit 10.0.101.11 \
    --username admin --password '<камерын нууц үг>'
```

Дараа нь `sudo systemctl restart parking-backend` (event poller шинэ нэвтрэлтийг
дахин холбогдох үедээ авна).

### Холболт шалгах

```bash
sudo /root/PARKING/backend/venv/bin/python /root/PARKING/tools/camera_check.py --all
```

Гаралтын дүгнэлт 3 төлөвтэй:

| Төлөв | Утга | Хийх зүйл |
|---|---|---|
| **БҮРЭН БЭЛЭН** | сүлжээ + нэвтрэлт + RPC2 бүгд OK | юу ч хийхгүй |
| **сүлжээ хэвийн · НЭВТРЭЛТ БУРУУ** | IP хүрч байгаа ч нууц үг таарахгүй | камерын нууц үгийг UI-аас оруулах (дээрх) |
| **СҮЛЖЭЭГЭЭР ХҮРЭХГҮЙ** | TCP 80 хаалттай | сүлжээний асуудал — нууц үгтэй хамаагүй |

Сүлжээгээр хүрэхгүй бол серверээс:

```bash
ip route get 10.0.101.10
```

Маршрут байхгүй эсвэл өөр gateway руу заавал сүлжээний багтай ярина.
