# Easy Parking — POS терминалын интеграцийн багц

Энэ хавтас нь **PAX A930 / Bonum POS** аппын хөгжүүлэгчид зориулсан бүрэн багц.

| Файл | Юу вэ |
|---|---|
| `PAX_POS_APP_GUIDE.md` | Гол заавар — урсгал, endpoint бүрийн тайлбар, жишээ хариу |
| `EasyParking_POS.postman_collection.json` | Postman collection — бүх дуудлага, автомат тест |
| `EasyParking_POS.postman_environment.json` | Postman environment — `base_url`, нэвтрэлт, хувьсагчид |

## Эхлэх

1. Postman дээр **Import** → дээрх хоёр JSON-ыг чирж оруулна.
2. Баруун дээд буланд **«Easy Parking — POS (тест)»** environment-ыг сонгоно.
3. Environment дотор `username` / `password`-оо бөглөнө (Easy Parking-аас олгоно).
4. **1. Нэвтрэлт → Login** ажиллуулна — `token` автоматаар хадгалагдана.
5. **2 → 3** дарааллаар ажиллуулна. `site_id`, `device_id`, `session_id`,
   `payment_id` бүгд автоматаар дараагийн хүсэлт рүү дамжина.

Тест орчин: `https://test.easy-parking.mn` · Прод: `https://site.easy-parking.mn`

## 2026-08-21-ний өөрчлөлт — аппад ЗААВАЛ хийх

| # | Өөрчлөлт | Аппад юу хийх |
|---|---|---|
| 1 | `GET /api/barriers/devices` | Хаалтны `device_id`-г эндээс авна. Өмнөх `/api/admin/devices` эрхээр хаагдсан (403). |
| 2 | `can_open` талбар | `false` бол **«Хаалт нээх» товчийг огт харуулахгүй** — эс бол оператор дараад 403 иднэ. |
| 3 | `payer_reg_no` | Худалдан авагчийн дугаарын талбар нэмнэ. 3 формат: ААН регистр (7 орон), ТТД (11–14), иргэний регистр (`АА00112233`). |
| 4 | `GET /api/payments/ebarimt/payer` | Регистр бичиж дуусмагц дуудаж **нэрийг** нь дэлгэцэд харуулна (иргэнд «НӨАТ төлөгч мөн/биш»). |
| 5 | `receipt` объект | Баримт хэвлэхэд ашиглана — зогсоолын нэр, дугаар, **орсон/гарсан цаг**, зогссон хугацаа, дүн, НӨАТ, ДДТД, сугалаа. |
| 6 | `GET /api/payments/pos/receipts` | «Сүүлийн гүйлгээ → Дахин хэвлэх» дэлгэц. |
| 7 | Ээлжийн `print_data` | Ээлж хаахад **Z-тайлан** хэвлэнэ (сувгийн задаргаа, зөрүү). |
| 8 | `X-App-Version` толгой | Хүсэлт бүрд аппын хувилбарыг илгээнэ — алдаа мөшгихөд зайлшгүй. |

## Асуулт

Заавар дахь endpoint бүрд хариултын жишээ бий. Тодруулга шаардвал Easy Parking-ийн
техникийн багтай холбогдоно уу.
