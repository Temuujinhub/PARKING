# Бүртгэлтэй машин, экспорт, устгал ба зогсоолын байршил

## Бүртгэлтэй машины хуудас

Жагсаалт анх нээгдэхэд 100 мөр авна. `Өмнөх` / `Дараах` товчоор дараагийн
хуудас руу орно. Нийт тоо нь бүх шүүгдсэн бүртгэлийн тоо. Байгууллагын нэрийг
бичиж хайхад хамгийн ихдээ 30 санал гарна. Давхардлын шалгалт тусдаа товчтой.

- **Зогсоолоор экспорт:** зогсоолоо сонгоод `Шүүлтүүрийн бүх мөрийг экспортлох`.
  Харагдаж буй 100 мөрөөр хязгаарлахгүй. Одоогийн нэр/төрөл/төлөв/байгууллагын
  шүүлтүүрүүд үйлчилнэ. 50,000-аас их бол шүүлтүүрээ нарийсгах шаардлагатай.
- **Сонгосон мөрийн экспорт:** checkbox-оор сонгоод `Сонгосныг экспортлох`.
  Хуудас солиход сонголт хадгалагдана, шүүлтүүр өөрчлөхөд цэвэрлэгдэнэ.
- Толгойн checkbox **энэ хуудсыг** сонгоно. `Шүүлтүүрийн бүх N мөрийг сонгох`
  товч нь 2,000 хүртэлх таарсан мөрийг хуудсуудыг дамнан сонгоно.
- Файл `.xlsx`; дугаарын эхний тэг хадгалагдана, нэр/тэмдэглэл томьёо болж
  ажиллахгүй. Огнооны баганууд UTC гэж тэмдэглэгдсэн.
- Зогсоолын шүүлтүүр нь тухайн зогсоолд **оноосон бүртгэлийг** харуулна.
  `Бүх зогсоолын эрхтэй` гэсэн тусдаа сонголт нь `site_id=null` бүртгэлүүд.
  Энэ нь тухайн мөчийн төлбөргүй нэвтрэх эрхийг тооцсон тайлан биш.

## Бөөнд нь устгах

Зөвхөн `drivers` эрхтэй ADMIN / SUPER_ADMIN өөрийн хүрээний сонгосон бүртгэлийг
устгана. Эхлээд нэр, дугаар, төлөв болон тоог үзүүлнэ. Дараа нь `УСТГАХ` гэж
бичиж батална. Харах ба батлах хооронд мөр өөрчлөгдвөл HTTP 409 буцааж дахин
шалгуулах бөгөөд нэг ч мөр устгахгүй.

Бүртгэл бүрийн өмнөх утга аудитад хадгалагдаж, устгалтай нэг transaction-д
commit хийнэ. Өмнөх зогсолт, төлбөр, wallet, өрийн мөрийг өөрчлөхгүй. Бүртгэлийн
үнэгүй нэвтрэх эрх цааш үйлчлэхгүй; өөр давхар бүртгэл байвал тэр нь тусдаа хэвээр.
UI-д буцаах товч байхгүй. Устгал нь бүх админ/импортын өөрчлөлттэй ижил
PostgreSQL transaction lock ашиглана.

## Зогсоолын байршил тохируулах

`Тохиргоо → Зогсоол → Засах` (мөн шинэ зогсоолын wizard) дотор:

1. Google Maps HTTPS холбоосыг оруулна.
2. Зогсоолын **орох хэсгийн** өргөрөг, уртрагыг хоёуланг нь оруулна.
3. `Цэгийг газрын зурагт шалгах` холбоосоор цэгийг нягтлаад хадгална.
4. Сул зай, дүүргэлтийн хувьд зогсоолын **багтаамжийг** бодит тоогоор тохируулна.

Богино `maps.app.goo.gl` холбоосыг хадгалж болно. Сервер уг холбоосыг даган
хүсэлт явуулахгүй; богино холбоосыг координат болгон автоматаар хөрвүүлэхгүй.
`q=lat,lng` / `query=lat,lng` бол UI туслах товчоор координатыг хуулж болно.
`@lat,lng` нь харагдацын төв байж болох тул орох цэг гэж таахгүй.
Хоёр координат хоёулаа хоосон байж болно; нэг нь дангаараа байж болохгүй.

Шалгах холбоос нь [Google Maps URLs албан зааврын](https://developers.google.com/maps/documentation/urls/get-started)
`/maps/search/?api=1&query=latitude,longitude` форматыг ашиглана. Google API key шаардахгүй.

## Easy Wallet болон бусад түншийн API

Одоо байгаа endpoint-ийг нэмэлт талбаруудаар өргөтгөсөн:

```http
GET /api/v1/sites
Host: site.easy-parking.mn
X-API-Key: <тухайн түншийн түлхүүр>
```

Түлхүүрийг `Тохиргоо → Холболт → Гадаад API` хэсэгт удирдана. Байршил харах
түншид төлбөрийн эрх өгөх шаардлагагүй. Зогсоолд хязгаарласан түлхүүр зөвхөн
тэр зогсоолыг авна. Зөвхөн идэвхтэй зогсоолууд гарна. Түлхүүрийг URL эсвэл
олон нийтэд түгээдэг frontend bundle-д хийхгүй; түнш өөрийн backend-ээс дуудна.
Одоогийн `read` түлхүүр бусад лавлах API-д ч эрхтэй тул зөвхөн итгэмжлэгдсэн
түншид өгнө. Энэ өөрчлөлт шинэ түлхүүр автоматаар үүсгэхгүй.

Зохиомол хариу:

```json
{
  "sampled_at": "2026-10-09T04:00:00Z",
  "sites": [{
    "site_code": "DEMO", "name": "Туршилтын зогсоол", "zone_code": "A",
    "address": "Жишээ хаяг", "latitude": 47.918, "longitude": 106.917,
    "google_maps_url": "https://www.google.com/maps/search/?api=1&query=47.918%2C106.917",
    "location_available": true, "capacity": 100, "occupied": 75, "free": 25,
    "occupancy_percent": 75.0, "over_capacity": false,
    "occupancy_source": "open_sessions", "occupancy_is_estimate": true,
    "sampled_at": "2026-10-09T04:00:00Z"
  }]
}
```

- `location_available=false`: координатгүй; газрын зурагт цэг тааж зурахгүй.
- `occupied`: OPEN / AWAITING_PAYMENT / PAID зогсолтын тооцоо. Эцэг/дотор тусдаа
  зогсоолтой бол дотогш орсон давхар зогсолтыг эцэг талбайгаас хасна. Нэг
  зогсоолын дотоод камер дангаараа энэ тоог хасахгүй. Админтай ижил тооцоолол.
- `capacity=0`: хязгааргүй/тохируулаагүй; `free=null`, `occupancy_percent=null`.
- Тоо багтаамжаас хэтэрвэл `free=0`, `over_capacity=true`; бодит тооцоог
  нуухгүй, хувь 100-аас их байж болно. Энэ тохиолдолд камер/хаалтын бүртгэлийг шалгана.
- `sampled_at` нь сервер энэ тооцоог авсан UTC цаг; камерын хамгийн сүүлийн
  heartbeat биш. Уншилт алдагдвал зөрүүтэй байж болох **ойролцоо** тоо.
- Хариунд жолооч, машины дугаар, төлбөрийн дүн, нууц түлхүүр байхгүй.
  Түнш кэш болон retry backoff хэрэглэж, ижил жагсаалтыг хэрэглэгч бүрээр
  давтан татахгүй байхаар нэгтгэнэ. Тодорхой polling SLA-г энэ өөрчлөлт тогтоохгүй.

## Release шалгалт

Production-ийн 32172400 суурь дээр бэлтгэсэн. Зөвхөн nullable 3 байршлын багана,
жагсаалтын 2 индекс нэмнэ; хуучин бүртгэл, санхүү, тохиргооны утгыг нөхөж бичихгүй.
Migration ба backend/frontend хамт суух шаардлагатай. Өмнөх schema revision дээр
шинэ ORM-г шууд асааж болохгүй.

CI PostgreSQL 16 / 18.6 дээр хуучин баганагүй сангийн upgrade, migration replay,
ижил эрэмбэтэй мөрүүдийн pagination, устгалын writer lock-ийг шалгана.
Production-д оруулахын өмнө шинэ backup-ийн тусдаа сэргээсэн хуулбар дээр migration,
өгөгдөл хадгалалт болон rollback/schema readiness-ийг шалгана. Энэ код өөрөө
production deploy, бүртгэлийн устгал/идэвхжүүлэлт, координат нөхөлт хийхгүй.
