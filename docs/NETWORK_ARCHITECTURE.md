## Deploy урсгал (одоо мөрдөж буй)

1. Cloud (test.easy-parking.mn) дээр bundle бэлдэж `/var/www/parking/upd-<commit>-<token>.bundle` болгож тавина.
2. Windows машинаас татаж авна: `https://test.easy-parking.mn/upd-....bundle`
3. `scp <файл> easyparking@172.16.100.21:/tmp/upd.bundle`
4. Сервер дээр: `sudo bash /root/PARKING/deploy/update.sh /tmp/upd.bundle`
   (DB backup → код → build → restart; .env/өгөгдөлд хүрэхгүй. Backend restart
   ~5-10 секунд — намуухан мөчид хийх нь зүйтэй; камерын стрим/поллер автоматаар
   дахин холбогдоно.)
